# ProVault case-study imagery

Eight illustrative device mockups of the ProVault platform, created with the built-in image-generation tool using the live-build presentation images as references. The four additional shots show a production desk, coastal mobile use, an overhead workspace and a laptop close-up. The scenes are presentation imagery, not documentary photographs of customers or physical deployments. Fine interface details may differ from the live app.

Files without a width suffix are 1536 × 1024 WebP masters; 960w and 480w variants support responsive loading. Original PNGs, full prompts and reference records are retained in the SHOWSET workspace under output/provault-natural and output/provault-natural-more.
